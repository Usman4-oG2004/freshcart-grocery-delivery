📡 Real-Time

Live GPS Tracking
Powered by Socket.io

Drivers broadcast their GPS coordinates every 10 meters. Customers watch a live animated map with ETA — no polling, pure WebSockets.

🚗
Driver broadcasts location
Every 10 meters, the driver app emits GPS coordinates via socket.io to the server.
⚡
Server relays instantly
The tracking socket forwards the update to the customer's order room in real-time.
🗺️
Map animates smoothly
The customer sees the driver marker glide across the map with live ETA calculations.
🔔
Status push notifications
FCM push notifications fire on order milestones: confirmed, picked up, delivered.

🌐 REST + WebSocket API

Clean API design

RESTful endpoints for all resources, plus a Socket.io layer for real-time live tracking events.

🔐 Authentication
POST/api/auth/register
POST/api/auth/login
GET/api/auth/me
PUT/api/auth/update-profile
POST/api/auth/add-address
🛍️ Products
GET/api/products — search, filter, paginate
GET/api/products/:id
POST/api/products — admin only
PUT/api/products/:id
DEL/api/products/:id
📦 Orders
POST/api/orders — place order
GET/api/orders/my — user history
GET/api/orders/:id
PUT/api/orders/:id/status
POST/api/orders/:id/rate
